Find symbols by name, ignoring case: exact match, then prefix, then fuzzy.

When: Instead of grep to locate a class, function or method: it matches names, not text, and returns IDs the other commands accept.
Returns: Matching symbols with kind, location and ID; for a misspelled name, the symbols of the closest name and the other close names.
Needs: tier 1 (symbols); see `codix capabilities`.

Usage: codix find [OPTIONS] <QUERY>

Arguments:
  <QUERY>
          Name to look for

Options:
      --exact
          The name equals the query

      --json
          Print JSON instead of text

      --prefix
          The name starts with the query

      --root <PATH>
          Use the project at this directory instead of searching upward

      --fuzzy
          The name is within a few edits of the query

      --glob
          The qualified name matches a glob, such as 'Invoice.*', quoted for the shell

  -E, --regex
          The qualified name holds a match of a regular expression, such as '^Invoice\.get', quoted for the shell

  -s, --case-sensitive
          Match case, which every mode ignores by default

      --kind <KIND>
          Keep symbols of this kind, such as method; repeatable

      --lang <LANGUAGE>
          Keep symbols of this language; repeatable

      --here
          Limit results to the current directory's subtree

      --path <DIR>
          Limit results to this subtree; repeatable

      --exclude-path <DIR>
          Leave out this subtree; repeatable

      --sources <SOURCES>
          Keep main or test sources only, as the build systems declare them
          
          [possible values: main, test]

      --limit <LIMIT>
          Maximum number of results
          
          [default: 50]

      --after <PLACE>
          Return the results after this place, as a page's `next` gives it

      --count
          Return how many results there are, not the results

      --all
          Return every result, for scripts

      --files
          Return one row per file, with its number of results, paged by file

      --sort <ORDER>
          With files, `count` puts the files with the most results first, on one page
          
          [possible values: count]

  -h, --help
          Print help (see a summary with '-h')

Example:
  codix find Invoice --kind class
